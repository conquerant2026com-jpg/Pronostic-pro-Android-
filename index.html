Données Internet

Aucune source de scores ou de cotes en direct n'est configurée dans cette première version. Pour ajouter une API, il faudra choisir un fournisseur, créer une clé API et idéalement passer par un petit serveur intermédiaire afin de ne pas exposer la clé dans l'application.

Installer sur Android

  1. Héberge le dossier sur un site HTTPS (ou ouvre-le avec un serveur local compatible).
  2. Ouvre l'adresse dans Chrome sur Android.
  3. Menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Ce prototype est une application web installable (PWA), pas encore un APK natif signé.
